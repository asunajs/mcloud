# 任务台账（用户下达 → 落点 → 状态）

> **规矩（用户口径 2026-10-02）**：用户每下达一件事，就在本文件记一行 ——
> **下达时刻 / 完成时刻 / 状态 / 落点（文件与命令）**，以及**没做完的部分**。
>
> ⚠ 三条例外的写法，都是为了这份台账**可信**：
> 1. **时刻**：只写我确实知道的（会话里带的时间戳、日志、`git`）。不知道就写 `≈` 或 `未记录` ✗
>    —— 不要把"大概那会儿"写成精确时刻 ✗。
> 2. **状态**只用四种：`已上线`（跑在 :3000 上的那份 ✓）／`已落盘`（源码/前端产物改好、**未**重启 ✗）／
>    `待确认`（需要用户点一次或跑一次才能闭环 ✓）／`未做` ✗。
>    ⚠「已落盘」不等于「生效」✗：Rust 改动要 `cargo build` + `launchctl kickstart` 才上线 ✓，
>    前端改动 `npm run build` 后**刷新即生效** ✓。
> 3. **落点**要给**能自己跑的命令**或 `文件:行` ✓ —— 台账不是我的自述，是可核对的东西 ✓。
