mcloud 3.0.0

第一个正式版
中国移动云盘的自动化工具 · 一个可执行文件，既是命令行也是网页服务 · 相对上一个正式版 v0.1.0 的重点摘要

直播小红花

  • 修掉口令误判：入场/送礼/点赞不再被当成口令投出去
  • 每条口令都能看到领到了什么，不再只报总数
  • 默认最长收听 60 秒 → 180 秒

凭据（登录状态）

  • 每天到你设的钟点检查一次，该换才换；不需要换就跳过并写明原因
  • 每个登录用户各设各的钟点，互不影响
  • 账号页可一键刷新（手动刷新不看还剩多少天）

推送（通知）

  • 规则管「怎么发」，行为管「什么时候发」，一个行为可选多条规则
  • 默认保守、不刷屏；被限流会记日志
  • 每日上限填 0 表示不限

定时与编排

  • 定时页可直接选「编排」作为目标
  • 直播自动定时：按上游「下一场」自动设好

命令行更简单

  • mcloud 起网页服务；mcloud run 立即跑默认每日任务
  • 只操作本机管理员那一个用户，没有 --user 之类的选择

更安全的默认

  • 推送地址默认拒绝指向本机/内网
  • 连不上服务端时显示中文说明，不再是英文 Failed to fetch

Docker / 容器（Linux）

  • 仓库里有 Dockerfile 与 docker-compose.yml：docker compose up -d --build 就起服务；镜像里是静态 musl 二进制 + ca-certificates + tzdata，数据在命名卷里
  • CI 出的那份在 ghcr：ghcr.io/asunajs/mcloud，一个标签含 linux/amd64 与 linux/arm64，docker pull 按机器自动挑
  • 注意：docker.yml 已改成不跟 tag 自动跑，所以 3.0.0 在 ghcr 上有没有对应镜像属于待确认；这一层本机没验过（开发机没装 docker），以 docs/docker.md 为准

云朵中心任务（App 里的任务）

  • 列表改走新版接口：不再把已经过期的任务列出来，与 App 看到的一致，并补回之前缺的条目
  • 进度与文案照 App 显示：「完成进度 (17/31)」；状态词按上游那一档显示（「开启中」「下月再来」「去完成」），不再一律写「待做」
  • 新做出来：「去云盘图书馆阅读书籍」(604)、「和AI助手对话」(609)、「加入一个知识库」(547)、「查看"我的账单"」(1029)
  • 两条 App 任务修复：「登录移动云盘云朵中心」(1017) 补上页面初始化上报那一发；「完成一次邮件转存」(1020) 旧路径实测 404，改成 App 实拍的三发链 —— 真机两个账号各翻一次
  • 上游已做满的条目：只领奖、不再重复运行，也不再误报失败
  • 通知口接上：能读到「+100豆」与进度分子

日志与存储

  • 运行日志按需读盘：不再把 data/logs/ 全读进内存，打开某次运行的日志时才读
  • 服务端日志落盘到 data/server-logs/<日期>.jsonl；以前只在内存里，重启就清空
  • 设置页五个上限格：历史保留条数、单次运行日志行数、日志总量上限、服务端日志内存行数、服务端日志总量上限（日志上限默认 64 MB，按目录字节预算，不再是按行数封顶）
  • 日志页「加载更早的 N 行」一页页往上翻，并显示「已显示 N 行」

下载哪个

你的机器选哪个
Linux（Intel/AMD 64 位）x86_64-unknown-linux-gnu
Linux，系统较老或缺库x86_64-unknown-linux-musl（静态，不挑系统）
Linux（ARM 64 位）aarch64-unknown-linux-gnu
Windowsx86_64-pc-windows-msvc（zip）
  • 包名 mcloud-v3.0.0-<三元组>.tar.gz（Windows 是 .zip），各附一个 .sha256，一共 8 个资产
  • 这一版没有 macOS 预编译包：CI 的 macOS runner 太贵已去掉，macOS 请自行 cargo build --release
