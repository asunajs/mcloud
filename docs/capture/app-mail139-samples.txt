## 4. ④ 的 404 归因到了"那一条路由"，不是整片入口

④ 回的是 **JSON** 的 404（`{code:"404", msg:"访问资源不存在"}`），③ 回的是 HTML 的 —— 两句
形状不同，说明 ④ 这一枪被**应用层**接住了。但"应用接住"还差一步归因，所以带了一发
只读对照枪（同一台 `caiyun.feixin.10086.cn:7071`、同一个 `/ycloud/` 前缀、另一条路由）：
它回 `HTTP 200` + `code="0" msg="success"`。

⇒ **入口活着，挂的是 `signin/task/taskClickV2` 这一条路由**（或者它吃的是别的形状）。
对照枪顺带读到 notice 那一族的实况（同一份输出）：
`taskOneInfo={cloudStatus="2" sum="200" taskStatus="3"}`、
`taskTwoInfo={cloudStatus="0" progress="2" sum="100" taskStatus="2"}`。两点：
① 两槽的**键集合不同** —— `progress` 只出现在第二槽，第一槽没有 ⇒ 与 `internal/upstream/app_notice.go`
里"槽内字段全部可选"那份解析一致（那一格此前只有夹具依据）。
② 这一发**不推进 R1**（"`cloudStatus` 哪个值是未领"）：读到的仍是 `2` 与 `0` 两档，
`1` 那一档到今天**一次都没出现过** —— 与 R1 记着的读数面（同日四槽 ∈ {0,2}）逐字同型。

## 8. 资产侧两口 ⑤⑦：把"会话有效"与"路由没了"分开的就是这两发

同一张 ② 换到的会话（同一枚 `sid` / `rmkey`），打**另外两台**子域，两个账号各一次，
读数逐字同型：

```
⑤ surplusNum（直发，看体）：HTTP 200，体形状 ={code="S_OK" summary=str<21>
    var={benefitStatus=str<1> benefitSurplusCount=str<1>}}
⑤ 解析结果：benefitSurplusCount="0" benefitStatus="1"（缺键即空串）
⑦ getComposeId（直发，看体）：HTTP 200，体形状 (松散解)={code="S_OK" var=str<21>}
⑦ 解析结果：拿到号，长度 21（值不打印）
```

**这一格收了什么**：

1. **会话是有效的。** ③④ 的 404 之前有两种读法（"这一族在厂商侧已死" vs "这张票/这
   两枚值不被认"），⑤⑦ 把后者**排除**了 —— 同一枚 `sid` 在 `html5` 与 `appmail` 两台上
   都换到了 `S_OK` 与一枚可用的草稿号。⇒ R35 剩下的那一半收窄成一句话：
   **挂的是 `login/autologin.action` 与 `signin/task/taskClickV2` 这两条路由**，
   不再是"整片邮箱 web 入口"或"凭据"那一档（问句本身仍留着：厂商 App 今天走哪一条，
   只能真机取证，见 §6）。
2. **两个零实拍落码的解析器跟真实体对得上。** ⑤ 的 `var.benefitSurplusCount` /
   `var.benefitStatus` 两枚键名逐字如旧 TS 所说；⑦ 的体是**单引号壳**（`(松散解)` 那一档），
   即"先按严格 JSON 解、解不开再把单引号换成双引号"那一条**必须**存在 —— 只有严格档
   就一行读数都拿不到。这是本仓第一次实拍到"邮箱这一族的体不是合法 JSON"。
3. **`sid` 走百分号编码没有副作用**：⑤⑦ 的 URL 里 `sid` 都是编码后拼进去的（本号那枚是
   hex 形态 ⇒ 编码为恒等变换），与 §3 档 C 的裸拼读数合起来看，编码这一手在这一族
   **不是**风险位。

**这两发没有说什么**（别顺手 extrapolate）：

- ⑥⑧ 两口的写：当时是真缺口，同日更晚补上了（§9：⑧ 404、⑥ 被认）。⑧ 打的正是 ③ 那台
  `mail.10086.cn`，而 §8-1 证明"那台活着、只有它的一部分路由没了"—— 打上之后才知道它属于哪一类。
- ⑤ 的 `benefitSurplusCount="0"` 的**语义**仍没有样本（两号都是 `0`、`benefitStatus`
  都是 `1`，上游一个字都没解释）。⚠ 不许写成"权益用完了"。但 §9 给它加了一条**边界**：
  同一张会话里 ⑤ 回 `0` 的同时 ⑥ 被认 ⇒ 那一枚计数**至少不是**转换那一发的硬闸。
  这一句是实测，不是解释 —— "那它到底管什么"仍待样本。
- ⑦ 只**取号**，不发信：`mbox:getComposeId` 的产物是一枚草稿号，本仓不发
  `mbox:compose` ⇒ 1004 那一发（真发一封邮件）仍然**没有落码**，等用户拍板。

## 9. 资产侧那两口的**写**（⑧ / ⑥）：一条 404、一条被认，方向就此分开
